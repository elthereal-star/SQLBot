# Domain docs

This repository uses the single-context layout.

Before exploring or changing a domain, read the root `CONTEXT.md` when it exists and any relevant decisions under `docs/adr/`. These documents define project terminology and architectural decisions for agents.

The domain documentation layout is:

```text
/
├── CONTEXT.md
└── docs/
    └── adr/
```

The files are created lazily when domain terms or architectural decisions need to be recorded; their absence is not itself an issue.
