# Issue tracker: GitHub

Issues and specifications for this repository live in GitHub Issues for `elthereal-star/SQLBot`. Use the `gh` CLI for issue operations.

Pull requests are not treated as a triage request surface. Changes requested by the user are committed and pushed only to the fork unless the user explicitly asks for another workflow.

## Common operations

- Create: `gh issue create --repo elthereal-star/SQLBot`
- View: `gh issue view <number> --repo elthereal-star/SQLBot --comments`
- List: `gh issue list --repo elthereal-star/SQLBot`
- Comment: `gh issue comment <number> --repo elthereal-star/SQLBot --body "..."`
- Close: `gh issue close <number> --repo elthereal-star/SQLBot`
